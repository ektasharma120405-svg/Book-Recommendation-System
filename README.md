Overview

A Machine Learning–based Book Recommendation System using Popularity-Based Filtering and Collaborative Filtering (Cosine Similarity) to suggest books based on ratings and user behavior.

🛠️ Tech Stack

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

⭐ Features

Popularity-based recommendations

Personalized recommendations using collaborative filtering

Cosine similarity for finding similar books

🚀 Run

pip install -r requirements.txt
jupyter notebook
